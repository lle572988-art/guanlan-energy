Gumroad 购买闭环 — 只需 2 步

网站已自动处理：付完款跳转 thank-you 页、买家确认邮件、卖家订单通知。你只需在 Gumroad 粘贴下面 1 个 URL。

第 1 步：开启 Ping（约 30 秒）

1. 打开 Gumroad Settings

2. 左侧或页面中找到 Advanced（高级）

3. 找到 Ping 输入框

4. 粘贴下面整段 URL → Save

https://metaphysicflow.com/api/gumroad-ping

第 2 步：Checkout 自定义字段（收出生信息，可选但强烈建议）

1. Gumroad 左侧 Checkout → Checkout form

2. 点 + Add custom field，添加 3 个 Text 字段（可勾选 Required）：

  • Date of birth (YYYY-MM-DD)
  • Birth hour (e.g. Zi Hour 23:00–01:00)
  • Birth city / country (optional)

3. Apply to → 选 All products → Save changes

已自动生效（无需再配）

  • 首页 / 结果页点击购买 → Gumroad 弹窗结账（金色按钮，无粉色）
  • 付完款 → 自动跳转 thank-you 页
  • Ping 开启后 → 买家收确认邮件 + 你收订单通知邮件
